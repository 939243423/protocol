# protocol_repo 合规与用户协议静态站点

本目录包含「岛上提醒 (Island Notifier)」面向 App Store 审核、TestFlight 公测与用户的在线法律协议与合规政策页面。

## 目录结构

| 文件 | 类型 | 说明 |
| :--- | :--- | :--- |
| [`index.html`](./index.html) | HTML5 / CSS | 合规与政策中心首页，汇总产品定位、合规清单与各协议快速入口 |
| [`privacy.html`](./privacy.html) | HTML5 / CSS | 隐私政策全文，严格遵循 App Store 审核指南 5.1.1（数据收集与存储规范） |
| [`terms.html`](./terms.html) | HTML5 / CSS | 最终用户许可协议（EULA）与服务条款，明确离线工具权责与免责声明 |
| `app_icon.png` | PNG 图像 | 1024×1024 官方高清应用图标资产，用于协议页面品牌展示与审核物料 |
| `app_icon.jpg` | JPEG 图像 | 协议页面背景与社交媒体分享卡片封面图 |

## 合规核心条款说明（2026 年 10 月更新）

### 1. 零网络上传与本地处理承诺 (`privacy.html`)
- **剪贴板识别**：使用 iOS 系统级 Vision 框架与本地正则/NLP 进行即时解析，不向任何第三方服务器发送用户剪贴板内容。
- **定位权限**：仅在地铁通勤功能激活时使用 CoreLocation 获取基站与经纬度，用于到站判断与距离衰减算法，数据留存于设备沙盒与 App Group。
- **系统日历写入**：仅用于将学期课程节次日程写入本地系统日历，严禁读取或上传用户既有的私人日历事件。
- **麦克风与语音识别**：仅在用户主动按住语音按钮时调用 Apple 原生 Speech 框架在芯片端侧实时转录取件码或路线，音频数据不上传服务器，不保存录音文件。
- **系统聚焦搜索索引**：取件码基于 CoreSpotlight 在本地私有沙盒建立索引以供主屏下拉搜索，失效即注销，不涉及外部传输。
- **端侧语音合成与品牌检索**：调用 iOS 本地 AVSpeechSynthesizer 与无障碍神经人声离线朗读；公共品牌商标通过 iTunes Search API 检索官方图并缓存至 App Group，不附带用户个人隐私信息。
- **iCloud 私有容器同步**：Pro 多设备同步完全基于 Apple iCloud 私有数据容器（Private Database），端到端加密，开发者无法接触。
- **无第三方统计 SDK**：不集成任何商业推广、用户画像追踪或广告变现 SDK。

### 2. 服务范围与免责声明 (`terms.html`)
- **离线算法性质**：本软件提供的地铁通勤到站预计、课程时间提醒与取件码状态提示依赖设备传感器（GPS、加速度计、气压计）与用户本地输入。
- **不可抗力与误差**：地下隧道信号屏蔽、列车临时调度、系统后台进程限制等客观因素可能导致提醒微弱延迟，本产品作为辅助提示工具，不承担误车或迟到等连带责任。
- **高校课表与调课免责**：课前提醒与日历日程基于用户录入数据执行，遇临时调课或教室变更请以教务处官方系统为准。

## 部署方式

该目录为标准静态 HTML 网页，可直接托管于：
- **GitHub Pages**：推送到 `gh-pages` 分支或配置仓库根目录 `/protocol_repo` 作为 Pages 发布目录。
- **Cloudflare Pages / Vercel**：将根目录指向 `protocol_repo` 即可秒级完成全球 CDN 部署。
- **App Store Connect 填写**：
  - 隐私政策 URL 填入: `https://<domain>/privacy.html`
  - 用户许可协议 (EULA) URL 填入: `https://<domain>/terms.html`
